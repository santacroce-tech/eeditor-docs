Everything EEditor and EELisp can do, in one place

EEditor is a notes editor with an agenda, spreadsheets, forms and mind maps. EELisp is the small Lisp inside it, which you can also embed on its own. This catalog collects the tutorials and manuals of both, and an index of every function and command you can call.

A path through it

New to both? Take these in order. Each step stands on its own if you'd rather jump in.

  1. Install EEditormacOS, Windows or Linux — free, no account. Or try the example apps in your browser first.
  2. Your first hourA folder, two linked notes, an agenda that files things for you, a shortcut of your own, a form.
  3. The sample workspaceWhat an empty folder is offered: the welcome note, example forms, a mind map of every shortcut — readable here too.
  4. TRY ME — the PIM tutorialFifteen lessons on the agenda and the notes kept in step with it, each saying what to press and what you should see.
  5. The manualEvery feature, chapter by chapter: notes, agenda, sheets, forms, the REPL, keybindings.
  6. Learn the languageThe EELisp book: syntax, data, the database, the agenda and sheets from code.
  7. Look anything upSearch builtins, spreadsheet functions, snippets, editor commands and shortcuts below.
  8. Embed the enginePut EELisp in your own Rust program, in a browser, or behind a JSON pipe.

    About this catalog

    It is built from the two repositories, not written by hand: the manuals and sites are copied from them, every Markdown document is kept in this repository's content/ folder and published in the library, and the catalog is read from the engine's own function reference, the spreadsheet library, the snippets and the keybindings file. It is rebuilt every day and whenever this repository changes, so what you read here is what the code does.
